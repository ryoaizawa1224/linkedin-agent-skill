# li-reply

自分の投稿についたコメントを、全部同じ重さで扱わず、まず分類してから返信を書くSkill。

## 入力

コメント本文を、できれば名前・役割と一緒に使う。スクリーンショットでもよい。browser toolでスレッドをscrapeしない。

## 5分類

| 分類 | 内容 | 対応 |
| --- | --- | --- |
| **LEAD** | ユーザーが解決できる問題を具体的に話している | 実質的な回答 + 小さく次の接点 |
| **SUBSTANCE** | データ追加、反論、議論の発展 | 最も内容のある返信 |
| **PEER** | 同業・近い領域で関係を作る価値がある | 相手にも情報を返す |
| **SUPPORT** | 「いい投稿」、絵文字、tagなど | 短い返信で十分 |
| **NOISE** | pitch、spam、bad faith | 基本は反応しない |

件数を先に示し、LEAD → SUBSTANCE → PEER → SUPPORT → NOISEの順で処理する。

## 返信ルール

- 質問には公開返信の中でちゃんと答える。答えをDMへ人質に取らない。
- 相手の名前を使うなら自然に1回程度。
- 相手のコメント量に返信の長さを合わせる。
- 批判には正しい部分を先に認め、そのうえで自分の立場を示す。防御的にならない。
- Leadには公開で価値を返し、最後に必要なら小さな「手伝える」導線を置く。
- コメント欄の営業pitchには、返信して露出を与える必要はない。

## 出力

分類と件数を示した後、必要な返信をコピペ可能な形でまとめる。各返信は `$li-human` を通す。

**自動投稿しない。** 実際の返信操作はユーザーが行う。
